# 白日梦
世界是一所巨大的学校。虽然我更应该把它比作医院，因为你们显然没有上过学校，或者耻于表现出自己上过学校。所以，世界是一所巨大的医院。医院是什么？医院是装载希望的地方。可你们不明自这一点，也不知道希望是什么。你们总是把自己拉进医院来，然后说：“大夫，还有希望吗？”就这样，你们让医院从装载希望的地方变成了装载死人的地方。然后，你们让全世界都变成了装载死人的地方，连希望也变成了装载死人的地方。

全体默哀一下。病人代表上台向名校友献花。一个病人没有经过许可就起身发言：“太感谢你了老师。别人都劝我活下去，是你给了我不再活下去的勇气！”他没有经过许可就结束了发言，没有经过许可就走向窗边，没有经过许可就张开手臂从窗台上跳了下去。他拥抱着大地，睡着了。

住院部主任送走名校友后，回来给助理交代任务。第一，调查清楚到底是谁劝那个家伙活下去。第二，整栋一楼的窗户也加上铁栅栏。

“你以为我不想像他一样吗？谁都想像他一样，像一只无忧无虑的小鸟，随时随地远走高飞。但是我不能这么做。现在的我，已经不再是年轻人了，不再是当年那个满怀激情在希波克拉底像前宣誓的年轻人了。现在的我，是一个主任。”\
助理没绷住。

“傻逼。”

晚上，“小鸟”醒了，爬起来，回到病房，躺到床上，开始发烧。地上的几个小时，他身上的衣裳实在是太薄了。有人看见他时，他的体温已经恢复了正常，正常到似乎从来没有不正常过，而他的已经恢复到刚出生时的纯净，纯净得似乎从来没有沾染过尘埃。

负责检查“小鸟”的护士恰好不在。她的恋人离开了她，她不知道他去了哪里，但还是毅然决然地踏上了寻找的旅途。这几天，电视台要报道医院的情况，院长不得不做做工作，连值班护士也存了名额。此后就有两个人要轮流面对“小鸟”清澈的眼神。

“小鸟”用清澈的眼神看见的唯一形象是他的妈妈。妈妈在他很小的时候就死了。临死前，妈妈躺在病床上对他说：“别怕，妈妈不会离开你的。妈妈会化作人间的风风雨雨，永远守候在你身边。”

“小鸟”一生中谈过三次恋爱，每次都有一样的开始，一样的经过，一样的结束。女孩们从小到大都没见过长着一双翅膀，所以当“小鸟”第一次走进她们的生命时，她们无一例外认为这是上天的指示，是自己命运深刻的转折点。当她们被“小鸟”邀请去他家鉴定每一根羽毛的色彩时，她们感到无限的欢欣。当屋外突然乌云蔽日，电闪雷鸣，风雨大作，而屋内仍然平静安宁，她们感到无限的喜悦，幻想看着自己幸福的一生即将在此处落脚。这份幻想一直持续到她们连一把伞也没有却要走进狂风暴雨之中的时候。

“小鸟”的一生有妈妈的庇护，而护士就没那么幸运了。她永远在回想她的恋人离开她的前一天。他第一次将她揽入怀抱，她把笑容埋在他的胸前，不让任何人看见。然而他说：“你一点也不了解真正的我。”她紧紧地抱住他，插嘴说：“那让我再多了解一点你好吗？”她抬起满是星光的眸子，诧异他对上她悲哀的目光。他告诉她，她眼中的他并不是他的第一个身份，也不是他将抛弃的最后一个身份。从前有一天，他突然意识到，世界是一场巨大的游戏。随即他意识到，自己一旦有了这个认识，便回不去从前的生活了。他的人生只剩下一个又一个的副本。她被他全心全意爱着，但她不是第一个，也不是最后一个，而且她不会知道自己是第几个，还会有几个。

第一个劝“小鸟”活下去的医生最近生活很不如意，直到住院部部长当上院长前后才算拨云见日，苦尽甘来。一家海外的医药公司向他抛出橄榄枝，他二话没说就答应了。他飞快地把自己的所有东西装进纸箱子里带走，没跟任何人打招呼就离开了。

医院里所有病人、医生、护士、其他工作人员的信息全都没了。还好数据是死的，人是活的，只要人在，没了的信息就可以重新录入。

“小鸟”终于不用看见这个世界了。半夜，一个男人进入“小鸟”的房间。小鸟此时睁着眼，二人对视，然后男人用枕头蒙住了“小鸟”的脸。

整个医院被男人布满了炸药。当上班打迟到的时候到来，他按下起爆器，然后医院就从世界上消失了。

这天整个医院只有住院部主任一个人上班迟到。

在连续寻找了二十三小时五十九分五十八秒后，护士终于合上了眼皮。她一连做了三个梦。第一个梦很恐怖，但是她想不起来了。第二个梦是她参加一个沉浸式交互剧本杀，其中所有角色都参加了一场神秘的游戏。失败的代价是死亡，胜利的奖励是三千元。但是，只有一个被称作许可的人能够获得胜利。明面上的规则是这样写的，然而所有人还知道另一件事：每个游戏参与者都另有目的，但玩家不知道自己扮演的角色的真正目的是什么。游戏的隐藏获胜条件便是认识并实现自己角色的真正目的。她在游戏中被砍掉了头，却仍然活着，活到不好意思继续活下去为止。她后来知道这是普通结局。紧接着是第三个梦，清晨，在一个天桥上，她遇见了她的恋人。他和她接吻，然后告别，约定傍晚时分再相见。等到黄昏，她看见他和她的另一个熟人一同站在天桥上。她确信这两人间没有任何直接关联。那个熟人消失了，她的恋人一看到她就跑了，她赶紧追上去。她追着他在一个县城的扶梯上上下下，跑过一个小区旁边的一座高架桥。跑到一个十字路口时，他停下了。他对她说，等到她真正拥有成为一个爱人的条件之时，他自会与她相见。然后她醒了。她已睡了很久但是她不甘心。于是她重新闭上了眼睛。

她回到那个十字路口，对着她的恋人大声地说出了他想抛弃却抛弃不掉的名字。他瞬间泪流满面，紧紧地抱住她，不住地说：“我现在只是个凡人了！我现在只是个凡人了！”
